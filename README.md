## Step 1: Install Python (Latest official)

This Step 1 lists the official/latest Python download pages and recommended installers for all major OS types (Windows, macOS, Linux, Android, iOS). Where mobile platforms don't have an "official CPython app", recommended, well-known ports/clients are listed. Always prefer the official Python downloads at python.org for desktop/server installs.

Quick verification after install:
- Check interpreter: `python3 --version` (or `python --version` on some Windows installs)
- Check package manager: `pip3 --version` (or `pip --version`)

Official universal download page (always shows the latest stable release):
- https://www.python.org/downloads/

Platforms
- ![Windows](assets/icons/windows.svg) Windows
  - Official Windows downloads (installers, embeddable zip, docs):  
    https://www.python.org/downloads/windows/
  - Notes:
    - Choose the appropriate installer for your CPU (Windows x86-64 executable installer is common).
    - Select "Add Python to PATH" during the installer if you want `python`/`python3` to be available from the command line.
    - Portable/embeddable options available on the Windows downloads page.

- ![macOS](assets/icons/macos.svg) macOS
  - Official macOS downloads (installers & macOS framework builds):  
    https://www.python.org/downloads/macos/
  - Alternate (package manager): Homebrew — https://brew.sh/  
    - Install via Homebrew: `brew install python` (keeps things up-to-date and integrates with macOS workflows).

- ![Linux](assets/icons/linux.svg) Linux / Unix
  - Official source releases and guidance:  
    https://www.python.org/downloads/source/  
    https://docs.python.org/3/using/unix.html
  - Recommended approaches:
    - Use your distribution package manager (apt, dnf, pacman, zypper) for system integration.
    - For multiple Python versions or user-level installs, use pyenv: https://github.com/pyenv/pyenv
    - For Debian/Ubuntu, consider deadsnakes PPA for newer releases: https://launchpad.net/~deadsnakes/+archive/ubuntu/ppa
  - Building from source: follow the "source" page and Unix guide linked above.

- ![Android](assets/icons/android.svg) Android (mobile)
  - Note: CPython official release is distributed from python.org (source/binaries). Full native CPython apps for Android are provided by third-party projects/ports — below are widely-used options:
    - Termux (terminal environment, install Python via package manager):  
      F-Droid: https://f-droid.org/en/packages/com.termux/  
      Play Store: https://play.google.com/store/apps/details?id=com.termux
    - Pydroid 3 (educational/IDE approach):  
      Play Store: https://play.google.com/store/apps/details?id=ru.iiec.pydroid3
    - QPython:  
      Play Store: https://play.google.com/store/apps/details?id=org.qpython.qpy3
  - For production mobile apps that embed Python, look at projects like Chaquopy or python-for-android.

- ![iOS](assets/icons/ios.svg) iOS (mobile)
  - Note: There is no single "official" CPython app on iOS; these are popular third-party apps for running Python on iPhone/iPad:
    - Pyto (open-source-ish, modern interpreter/IDE):  
      App Store: https://apps.apple.com/app/pyto-python-3/id1436650069
    - Pythonista (mature, paid IDE):  
      App Store: https://apps.apple.com/app/pythonista-3/id1085978097
    - Carnets (Jupyter notebook server for iOS):  
      App Store: https://apps.apple.com/app/carnets/id1450994948

- ![Python](assets/icons/python.svg) Python (branding)
  - Official homepage: https://www.python.org/
  - Always prefer python.org for official source and installers. Verify checksums and signatures for production/system installs.

Security / verification
- Verify downloads and checksums where available (especially installers and source tarballs) using the files list on python.org:
  - Files & checksums: https://www.python.org/downloads/
- Prefer HTTPS downloads and verify signatures/checksums for server or production installs.

Recommended tooling around Python
- pyenv (manages multiple Python versions): https://github.com/pyenv/pyenv
- pipx (run Python CLI apps in isolated venvs): https://pypa.github.io/pipx/
- virtualenv / venv (virtual environments): https://docs.python.org/3/tutorial/venv.html
