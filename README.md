## Installation Steps

### Step 1: Install Python (Latest Official)

![Python](assets/icons/python.svg) **Python** is the foundation of this software stack and is required for many development tools and package managers.

#### Download Python for Your Platform:

- ![Windows](assets/icons/windows.svg) **Windows**: Download from [python.org/downloads/windows](https://www.python.org/downloads/windows/)
  - Recommended: Use the official Windows installer (64-bit) for the latest stable version
  - **Important**: Check "Add Python to PATH" during installation

- ![macOS](assets/icons/macos.svg) **macOS**: Download from [python.org/downloads/macos](https://www.python.org/downloads/macos/)
  - Alternatively, use Homebrew: `brew install python3`

- ![Linux](assets/icons/linux.svg) **Linux**: Use your distribution's package manager
  - Ubuntu/Debian: `sudo apt update && sudo apt install python3 python3-pip python3-venv`
  - Fedora: `sudo dnf install python3 python3-pip`
  - Arch: `sudo pacman -S python python-pip`

- ![Android](assets/icons/android.svg) **Android**: Use [Termux](https://termux.dev/) or [Pydroid 3](https://play.google.com/store/apps/details?id=ru.iiec.pydroid3)
  - Termux: `pkg install python`

- ![iOS](assets/icons/ios.svg) **iOS**: Use [Pythonista](https://omz-software.com/pythonista/) or [Carnets](https://holzschu.github.io/Carnets_Jupyter/)

#### Verify Installation

After installation, verify Python is correctly installed by opening a terminal/command prompt and running:

```bash
python --version
# or
python3 --version
```

You should see the Python version number (e.g., `Python 3.12.0` or later).
