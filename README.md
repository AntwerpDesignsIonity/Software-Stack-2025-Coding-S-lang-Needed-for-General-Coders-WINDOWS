## Installation Steps

### Step 1: Python Installation Paths

Before setting up the complete software stack, you need to know where Python is installed on your system. We provide comprehensive documentation and detection scripts for all platforms:

#### Documentation
- **[STEP1_PYTHON_INSTALL_PATHS.md](STEP1_PYTHON_INSTALL_PATHS.md)** - Complete guide to Python installation paths for:
  - **Windows** (Official Installer, Microsoft Store, Anaconda, Chocolatey)
  - **Linux** (Debian/Ubuntu, Red Hat/Fedora, PyEnv, Anaconda)
  - **macOS** (python.org, Homebrew, PyEnv, Anaconda)
  - **Android** (Termux, QPython, Pydroid 3, Chaquopy)
  - **iOS** (Pythonista, Pyto, Carnets, iSH, a-Shell)

#### Detection Scripts
Use these scripts to automatically detect Python installations on your system:

**For Windows:**
```powershell
.\step1_detect_python.ps1
```

**For Linux/macOS/Unix:**
```bash
./step1_detect_python.sh
```

**For Android (Termux):**
```bash
bash step1_detect_python.sh
```

These scripts will search your system for Python installations and display their paths, versions, and configurations.
