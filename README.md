## Step 1: Install Python (Latest official)

![Python](assets/icons/python.svg) **Python** - Required for running automation scripts and many development tools.

### ![Windows](assets/icons/windows.svg) Windows

1. Visit the official Python website: [https://www.python.org/downloads/](https://www.python.org/downloads/)
2. Download the latest Python 3.x installer for Windows
3. Run the installer
4. **Important:** Check "Add Python to PATH" during installation
5. Verify installation by opening Command Prompt or PowerShell and running:
   ```bash
   python --version
   ```

### ![macOS](assets/icons/macos.svg) macOS

1. Visit the official Python website: [https://www.python.org/downloads/](https://www.python.org/downloads/)
2. Download the latest Python 3.x installer for macOS
3. Run the installer package
4. Verify installation by opening Terminal and running:
   ```bash
   python3 --version
   ```

**Alternative (using Homebrew):**
```bash
brew install python3
```

### ![Linux](assets/icons/linux.svg) Linux

Python is usually pre-installed on most Linux distributions. To install or update:

**Debian/Ubuntu:**
```bash
sudo apt update
sudo apt install python3 python3-pip
```

**Fedora/RHEL:**
```bash
sudo dnf install python3 python3-pip
```

**Arch Linux:**
```bash
sudo pacman -S python python-pip
```

Verify installation:
```bash
python3 --version
```

### ![Android](assets/icons/android.svg) Android

For Android development with Python:

1. Install **Termux** from F-Droid or Google Play Store
2. Open Termux and run:
   ```bash
   pkg update
   pkg install python
   ```
3. Verify installation:
   ```bash
   python --version
   ```

**Alternative:** Use **Pydroid 3** app from Google Play Store for a full Python IDE on Android.

### ![iOS](assets/icons/ios.svg) iOS

For iOS development with Python:

1. Install **Pythonista** from the App Store (paid app)
   - Full Python 3 environment with IDE
   - Includes many popular libraries

2. **Alternative:** Install **a-Shell** (free) from the App Store
   - Terminal environment with Python support

3. **Alternative:** Use **Juno** or **Carnets** for Jupyter notebooks on iOS
