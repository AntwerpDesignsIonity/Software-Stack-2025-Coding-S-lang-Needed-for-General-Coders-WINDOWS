# Ionity Software Stack Metadata

## Project Information

This repository contains the Ionity Comprehensive Language Installer, a cross-platform GUI tool for installing programming languages, runtimes, SDKs, and CLI tools.

## Supported Languages and Tools

The installer supports 24 programming languages and development tools:

1. **JavaScript** - Node.js runtime and npm
2. **Java** - JDK (OpenJDK or Oracle)
3. **PHP** - PHP runtime and CLI
4. **Python** - Python 3 interpreter and pip
5. **Rust** - Rust toolchain
6. **Swift** - Swift compiler
7. **C++** - Compilers (gcc, g++, clang, MSVC)
8. **C#** - .NET SDK
9. **Ruby** - Ruby interpreter
10. **R** - R statistical computing
11. **SQL** - SQLite, PostgreSQL clients
12. **Kotlin** - Kotlin compiler
13. **TypeScript** - TypeScript compiler (via npm)
14. **MATLAB** - Commercial computing environment
15. **Perl** - Perl interpreter
16. **Go** - Go programming language
17. **Dart** - Dart SDK
18. **Visual Basic** - Part of Visual Studio
19. **Scala** - Scala language
20. **CSS** - PostCSS and Autoprefixer tooling (via npm)
21. **Assembly** - NASM assembler
22. **Objective-C** - Part of Xcode
23. **Delphi/Object Pascal** - Delphi IDE
24. **Ada** - GNAT compiler

## Platform Support

- **Windows** - Using winget package manager
- **macOS** - Using Homebrew package manager
- **Linux** - Using apt/dnf package managers
