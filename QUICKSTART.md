# Quick Start Guide

## 3 Simple Steps to Get Started

### Step 1: Install Python First ⚠️

**Python is required to run this installer!**

1. Go to: https://www.python.org/downloads/
2. Click "Download Python"
3. Run the installer
4. ✅ **CHECK "Add Python to PATH"** (very important!)
5. Complete installation

### Step 2: Download & Run the Installer

Download `software_stack_installer.py` and run it:

```cmd
python software_stack_installer.py
```

### Step 3: Select & Install

1. Choose your installation directory
2. Check the software you want
3. Click "Install Selected"
4. Follow the generated guide

## That's It! 🎉

The installer will create:
- ✅ Download shortcuts for each component
- ✅ A detailed installation guide (INSTALLATION_GUIDE.txt)
- ✅ Instructions for installation order
